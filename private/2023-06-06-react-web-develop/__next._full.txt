<h1>프로젝트 구조 설정</h1>
<h2>tailwind 설치 및 사용법</h2>
<p><code>tailwind</code>를 사용하게 된 이유는 따로 css 파일을 생성하지 않고도 해당 jsx 파일에서 class 설정으로 간단하게 css 적용이 가능합니다.
<br>
고로 편리하고 직관적으로 코드를 관리할 수 있기 때문에 도입하게 되었습니다.</p>
<h3>tailwind 설치</h3>
<pre><code class="hljs language-shell"><span class="hljs-meta prompt_"># </span><span class="bash">개발자 모드로 설치</span>
npm instal -D tailwindcss
<span class="hljs-meta prompt_">
# </span><span class="bash">tailwind.config.js 생성!</span>
npx tailwindcss init
</code></pre>
<p><code>tailwind.config.js</code> 파일에서 <code>content</code> 설정을 해줍니다.
<br>
(js, jsx 파일에서 <code>tailwind</code>를 사용할 수 있도록 설정!)</p>
<pre><code class="hljs language-javascript"><span class="hljs-comment">/** <span class="hljs-doctag">@type</span> {<span class="hljs-type">import('tailwindcss').Config</span>} */</span>

<p><code>index.css</code>에서 설정을 추가해줍니다.</p>
<pre><code class="hljs language-css"><span class="hljs-keyword">@tailwind</span> base;
